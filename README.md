# Гавань

Воксельный веб-симулятор островного город-государства. Антистресс-игра про заботу о жителях:
ты приплываешь на пустой остров с четырьмя людьми и обустраиваешь место, где им будет хорошо.

Ни врагов, ни таймеров, ни проигрыша. Никто не умирает и не уходит.

## Как запустить локально

Нужны **Node 22+**, **pnpm 10+** и **Docker** (только ради базы данных).
Без базы игра теперь не запускается: мир считает сервер, и он же его хранит.

```bash
# 1. Зависимости
pnpm install

# 2. Настройки: скопировать образец, править обычно ничего не нужно
cp .env.example .env

# 3. База данных
docker compose up -d
pnpm db:migrate

# 4. Запуск
pnpm dev
```

Клиент откроется на <http://localhost:5173>, сервер — на <http://localhost:3000>.

Первый экран попросит адрес почты. Настроенная почта для разработки не нужна: письмо
печатается в лог сервера — там же лежит и ссылка для входа, её можно открыть прямо из терминала.

### Проверки

```bash
pnpm check         # типы, линтер и тесты разом — то же, что гоняет CI
pnpm typecheck     # только типы
pnpm lint          # только линтер
pnpm test          # только тесты
pnpm format        # переформатировать код
pnpm build         # собрать клиент и сервер
```

### Если что-то не работает

| Симптом                                           | Что делать                                                                                                                                              |
| ------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------- |
| «Связь пропала» поверх острова                    | Сервер не отвечает. Проверь, что `pnpm dev` показал строку `Server listening at http://…:3000`. Клиент переподключится сам, как только сервер вернётся. |
| Ссылка для входа не приходит                      | В разработке письма не отправляются — они печатаются в лог сервера. Найди в выводе `pnpm dev` строку «письмо для …» и открой ссылку из неё.             |
| Сервер падает с «проблемы в переменных окружения» | Нет файла `.env` или в нём пусто. `cp .env.example .env`.                                                                                               |
| `pnpm db:migrate` не может подключиться           | База не поднята: `docker compose up -d`, подожди пару секунд и повтори.                                                                                 |
| Порт 5173 или 3000 занят                          | Останови старый процесс. Порт клиента задан жёстко намеренно — чтобы `WEB_ORIGIN` и CORS всегда совпадали.                                              |
| Ошибки типов после `git pull`                     | `pnpm install` — скорее всего изменились зависимости.                                                                                                   |

## Стек

- **Клиент:** Vite + TypeScript + three.js + React (только HUD) + zustand
- **Сервер:** Fastify + Drizzle ORM + PostgreSQL
- **Общий код:** `packages/shared` — типы, каталоги контента и ядро симуляции; чистые
  детерминированные функции без зависимостей, исполняются одинаково на клиенте и на сервере

## Статус

Пройдены этапы **M0 «Каркас»**, **M1 «Воксельный мир на экране»**, **M2 «Мир редактируется»**,
**M3 «Жители живые»**, **M4 «Строительство и экономика»**, **M5 «Сервер-авторитет»**,
**M6 «Офлайн и догон»**, **M7 «Душа»**, **M8 «Гости»** и **M9 «Полировка»**. Начат
**M10 «После запуска»** — возврат отложенного. Остров генерируется из числа-сида
и рисуется чанками, землю можно копать и насыпать, растения — сажать. По острову ходят четверо:
у каждого имя, две черты характера, свои нужды и настроение. Они спят по ночам, едят,
разговаривают и смотрят на воду.

Теперь на острове можно строить. В каталоге 40 зданий: жильё, добыча, мастерские, быт, культура
и уют. Заказанное здание появляется стройплощадкой и растёт снизу вверх, жители поблизости
помогают. Готовое здание производит: место дровосека даёт дерево, лесопилка превращает его
в доски, из досок получается домик. Житель сам селится в свободный дом и идёт туда спать;
работу он тоже находит сам — по характеру, а игрок может решить иначе. Перенести здание можно
всегда и бесплатно, разобрать — с полным возвратом в первые десять минут.

Управление:

| Клавиша                                 | Что делает                                      |
| --------------------------------------- | ----------------------------------------------- |
| Правая кнопка, пробел с перетаскиванием | Панорама                                        |
| Колесо                                  | Зум                                             |
| `Q` `E`, `Alt` с перетаскиванием        | Поворот камеры                                  |
| `1` `2` `3` `4` `5`                     | Смотреть · копать · насыпать · сажать · строить |
| `B` `X` `C`                             | Размер кисти · материал · растение              |
| `R`                                     | Повернуть здание перед постановкой              |
| `V`                                     | Режим «Смотреть». Выход — любая клавиша         |
| `Escape`                                | Передумать строить                              |
| `Ctrl+Z`                                | Отменить                                        |
| `F3`                                    | Отладочная панель и ползунок времени суток      |

На телефоне: один палец — панорама, два — зум и поворот, двойное касание — приближение.
Нижний ряд кнопок заменяет клавиши, а здание ставится не касанием, а отдельной кнопкой —
палец закрывает как раз то место, куда целятся.

Клик по жителю в колонке справа открывает карточку, клик по зданию в режиме «смотрю» — карточку
здания. Склад в левом верхнем углу показывает четыре числа, остальное раскрывается по клику.

Мир теперь считает сервер. Вход — по ссылке из письма, паролей нет. Остров заводится сам при
первом входе и хранится в базе: обновление страницы, закрытая вкладка и перезапуск сервера
ничего не теряют. Ресурсы, время и производство считает только сервер — команда, отправленная
из консоли браузера, не даёт ни единицы дерева. Симуляция идёт лишь для островов, на которых
кто-то есть; разрыв связи не ломает игру и чинится сам.

Остров живёт и без игрока. Пока тебя нет, стройки заканчиваются, склад наполняется, кто-то
въезжает в новый дом, а настроение жителей сходится к спокойному — ниже него оно не опускается
никогда. Возвращение встречает экраном «Пока тебя не было»: три-шесть спокойных строк о том,
что случилось хорошего. Ни процентов, ни графиков, ни единого слова про потери. Если
рассказывать нечего — экрана нет вовсе.

У острова появилась душа. **Дневник** пишется сам, голосом жителей: «Пров перебирается в новый
дом. На берегу никого не было». Жители **дружат**, заводят **любимые места** и иногда чего-нибудь
**хотят** — скамейку на своём месте, фонарь у дома. Желание живёт в дневнике и в карточке
человека; не выполнил — не происходит ничего, и напоминания не будет. Новые люди **приплывают
сами**, когда есть где жить и вокруг хорошо. **Главы** переключаются по вехам — тихо, крупно
и один раз. Клавиша **V** включает режим «Смотреть»: интерфейс уходит целиком, камера медленно
облетает остров по тому, что игрок построил.

На остров можно позвать друга. Владелец видит код в углу и копирует ссылку одной кнопкой;
гость заходит по ней, ходит камерой, читает дневник и может оставить подарок — из своего
склада, не из воздуха. Открытка выбирается из готового набора: свободного текста в игре нет
нигде, а значит, нет и модерации. След визита — цветок на берегу и запись в дневнике.
Ни счётчиков посещений, ни оценок, ни рейтингов островов.

Порт открывает торговлю: лодка меняет ракушки на что угодно по неизменному курсу, а ракушки
жители дают просто за хорошую жизнь. Это страховка от тупика: кончился камень — лодка привезёт.

Игра начинается с моря. Лодка причаливает, четверо сходят на берег, камера опускается,
и на экране одна строка: «Здесь будет хорошо». Дальше — тёплое пятно на песке там, где встанет
первый шалаш. Ни туториала, ни модальных окон, ни стрелок; сцена пропускается любой клавишей
и не повторяется.

Интерфейс проходится клавиатурой без мыши, размер букв переключается между 100, 125 и 150%,
а все индикаторы читаются в чёрно-белом снимке: настроение показано формой, отказ при постановке
здания — перечёркиванием, остановившееся здание — значком. Контраст текста проверяется тестом
по составленному цвету, а не на глаз.

Вокруг острова — два маленьких островка, и дойти до них пешком нельзя. Мостки кладутся
инструментом «насыпать» от берега или от предыдущей доски; как только настил дошёл, жители
начинают ходить туда сами. Не построишь мост — не произойдёт ровным счётом ничего.

Как развернуть игру, снимать резервные копии и проверять их восстановлением —
[`docs/deploy.md`](docs/deploy.md). Замеры производительности — [`docs/perf.md`](docs/perf.md).
