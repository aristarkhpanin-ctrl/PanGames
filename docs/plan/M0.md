# M0. Каркас

**Цель:** проект собирается, запускается и проверяется одной командой. Игры ещё нет — есть скелет,
на который всё дальнейшее можно вешать, не переделывая структуру.

**Вход:** пустой репозиторий с `CLAUDE.md`, `README.md` и `docs/`.
**ТЗ:** §1 (стек), §10 (структура репозитория), §11 (M0).

---

## Сессия 0.1 — Монорепозиторий и тулинг

Создать структуру workspace и настроить проверки, которыми будут пользоваться все следующие сессии.

**Что сделать**

- `pnpm-workspace.yaml`: пакеты `apps/*`, `packages/*`.
- Корневой `package.json` со скриптами: `dev`, `build`, `typecheck`, `lint`, `format`, `test`.
- Базовый `tsconfig.base.json`: `strict: true`, `noUncheckedIndexedAccess: true`,
  `exactOptionalPropertyTypes: true`, `target: ES2022`, `moduleResolution: bundler`.
  Пакеты наследуют его своими `tsconfig.json`.
- `packages/shared` — пустой пакет с `src/index.ts` и **нулём рантайм-зависимостей**.
  В его `package.json` и ESLint-конфиге запретить импорты `three`, DOM-типов и Node API.
- ESLint (flat config) + Prettier. Правила, которые обязаны быть включены:
  запрет `any`, запрет `Math.random()` и `Date.now()` внутри `packages/shared`, запрет циклических импортов.
- Vitest на уровне workspace, чтобы `pnpm -r test` работал из корня.
- `.gitignore`, `.editorconfig`, `.nvmrc`.

**Готово, когда**

- [ ] `pnpm install` проходит без ошибок
- [ ] `pnpm -r typecheck`, `pnpm -r lint`, `pnpm -r test` — все зелёные на пустом проекте
- [ ] Попытка написать `Math.random()` в `packages/shared` роняет линтер (проверено вручную)

## Сессия 0.2 — Клиент

**Что сделать**

- `apps/web`: Vite + TypeScript + React.
- Структура каталогов сразу по §10 ТЗ: `render/`, `input/`, `net/`, `state/`, `ui/`, `main.ts`.
  Пусть пока пустые с заглушками — это карта, по которой ориентируются следующие сессии.
- `main.ts`: инициализация three.js — рендерер, пустая сцена, перспективная камера, resize, render loop.
  На экране пока однотонный фон цвета `--sea-deep`.
- React монтируется **поверх** канваса отдельным корнем и ничего не знает о сцене.
- `state/store.ts`: пустой zustand-стор с заготовкой формы состояния.
- Шрифты `Unbounded`, `Golos Text`, `Caveat` подключены локально из бандла (не с CDN),
  подмножества с кириллицей. Табличные цифры для чисел настроены глобально.
- CSS-переменные палитры из §8 ТЗ — единственный источник цвета в интерфейсе.

**Готово, когда**

- [ ] `pnpm dev` поднимает клиент, в браузере пустая сцена и React-оверлей
- [ ] Кириллица во всех трёх шрифтах отображается корректно
- [ ] Сборка `pnpm build` проходит

## Сессия 0.3 — Сервер и база

**Что сделать**

- `apps/server`: Fastify, TypeScript, эндпоинт `GET /health` → `{ ok: true }`.
- Конфиг через переменные окружения с валидацией на старте (сервер не стартует с кривым конфигом),
  `.env.example` в репозитории.
- `docker-compose.yml` с PostgreSQL и томом для данных.
- Drizzle ORM: подключение, `db/schema.ts` пока с одной таблицей `users`, первая миграция,
  скрипты `db:generate`, `db:migrate`.
- CORS и логирование настроены для разработки.
- Клиент из 0.2 дёргает `/health` при старте и пишет результат в консоль.

**Готово, когда**

- [ ] `docker compose up -d` поднимает Postgres, `pnpm db:migrate` создаёт таблицу
- [ ] `pnpm dev` из корня поднимает клиент и сервер одновременно
- [ ] Клиент получает `{ ok: true }` с `/health`

## Сессия 0.4 — Непрерывная проверка и документация запуска

**Что сделать**

- GitHub Actions: на каждый push и PR — `install`, `typecheck`, `lint`, `test`, `build`.
  Кэш pnpm настроен, прогон укладывается в несколько минут.
- В `README.md` — раздел «Как запустить локально»: требования, три команды, типичные проблемы.
- `docs/decisions.md` — журнал технических решений: дата, решение, причина.
  Первая запись — почему three.js напрямую, а не react-three-fiber (§1 ТЗ).

**Готово, когда**

- [ ] CI зелёный на основной ветке
- [ ] Человек, который видит проект впервые, поднимает его по README без вопросов

## Чего не делать на этом этапе

- Не писать генерацию мира, воксели, мешинг — это M1.
- Не заводить таблицы БД сверх `users`. Схема из §9 ТЗ появляется на M5, когда известна её реальная форма.
- Не настраивать авторизацию, деплой, домены, мониторинг.
- Не добавлять UI-библиотеки и CSS-фреймворки. Интерфейс здесь свой, на CSS-переменных палитры.
- Не подключать react-three-fiber ни в каком виде — §1 ТЗ отказывается от него сознательно.
